## 🚀 Quick Start Guide

### Step 1: Add Your Resume
```bash
# Place your resume PDF in the portfolio directory
cp /path/to/your/resume.pdf /home/saipriya/portfolio/saipriya_resume.pdf
```

### Step 2: Test Locally
```bash
cd /home/saipriya/portfolio

# Option 1: Python (easiest)
python3 -m http.server 8000

# Option 2: Open directly
open index.html  # macOS
xdg-open index.html  # Linux
```

Then visit: `http://localhost:8000`

### Step 3: Customize (Optional)
Edit `index.html` to update:
- Name, title, contact info
- LinkedIn and GitHub URLs
- Experience details
- Project descriptions
- Skills and technologies

## 📈 Content Strategy

### What Recruiters Look For
1. **Clear Role** - "Backend Software Engineer II" prominent
2. **Impact** - Metrics everywhere (60%, 50%, 2x)
3. **Production Experience** - Real systems, not toy projects
4. **Technical Depth** - System design, architecture patterns
5. **Engineering Mindset** - Philosophy section
6. **Easy Contact** - Email, LinkedIn all visible

### Writing Style Principles
- **Active Voice**: "Built system..." not "System was built..."
- **Metrics First**: Start with numbers, then explain
- **Problem-Solution-Impact**: Framework for projects
- **Technology Context**: Why you chose specific tech
